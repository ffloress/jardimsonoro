BAUHAUS POSTER – EDITABLE PACKAGE
=================================

poster.svg            Layered, fully editable artwork with live text.
poster-outlined.svg   The same artwork with the text converted to shapes.
                      Looks exactly right everywhere, even without the fonts.
fonts/                The typefaces used in this poster (TrueType).

HOW TO EDIT
1. Install the fonts: double-click each file in "fonts" and click "Install"
   (macOS Font Book / Windows font viewer).
2. Open poster.svg in Affinity, Adobe Illustrator, Figma or Inkscape.
   The layers "Background", "Shapes" and "Text" come in as separate layers.
3. Save it in your app's own format (.af, .ai, .fig …) and keep designing.

Fonts in this poster:
- Josefin Sans: JosefinSans-Bold.ttf, JosefinSans-Regular.ttf

These font files contain the basic Latin character set (English, German incl.
umlauts, French, Spanish, Italian, Dutch, Scandinavian …). For other languages,
install the complete families from fonts.google.com.
